📦 Overview

This project is a self-contained, fully dockerized home server running on Ubuntu. It powers my media library, personal cloud, finance tracker, retro gaming platform, and also acts as my primary development machine. I can access and control everything from anywhere in the world — securely, reliably, and without relying on third-party services.

🧩 Key Features

  • 🎞️ Media Server:
    • Jellyfin for watching movies and TV shows
    • Immich for automatic photo backup and gallery
    • qBitTorrent for downloading torrents straight through the web ui, and continuous seeding.
  • ☁️ Personal Cloud:
    • Nextcloud for document storage, calendar sync, and sharing
  • 💰 Finance:
    • Firefly III for tracking expenses and budgeting
  • 🎮 Retro Gaming:
    • RetroArch Web to play retro games directly in the browser
  • 🧠 Dashboard UI:
    • CasaOS as the main control panel for all services

🛠 Server Stack

  • OS: Ubuntu
  • Containers: Everything runs inside Docker
  • Management UI: Portainer + CasaOS
  • Storage: Two hard drives combined to serve all data needs

🌐 Remote Access

  • Nginx Proxy Manager for managing subdomains and reverse proxy rules
  • Cloudflare DNS for custom domain access
  • WireGuard VPN for secure connection to the home network from anywhere

👨‍💻 Development on the Go

I use this server as my main development machine. All my personal projects, apps, and experiments are stored and run here. I SSH into the server from any device — laptop, tablet, or even phone — and continue coding with ease. Whether it's managing containers, running builds, or editing files, it's all done through my private server environment.

🔒 Security

  • All services run behind Nginx Proxy Manager with SSL
  • WireGuard ensures private access when remote
  • All apps are isolated in Docker containers
