A full-stack web application that simplifies the food court experience. Users can place orders from multiple stalls via QR codes, and merchants can manage menus, discounts, and track sales. Built for both customer convenience and vendor management.

🔑 Key Features

  • Customers scan QR codes at tables to access the menu from all restaurants.
  • Unified billing system with support for split payments.
  • Cart system supports quantity updates and live cost calculation.
  • Multiple payment options: Cash, Card, Mobile Banking.
  • Merchants can edit their menus, set discounts, and view order status.
  • Admins can add/edit/delete stores with image uploads.

🧭 User Interfaces

Customer Side

  • Home, Cart, and Login navigation
  • Cart system with real-time updates
  • Flexible payment flow with receipt generation

Merchant Side

  • View and manage live and past orders
  • Edit own store’s food items and discounts

Admin Panel

  • Secure login for admin access
  • CRUD operations on stores (including images)

🛠️ Tech Stack

  • Frontend: HTML, CSS, JavaScript
  • Backend: Django (Python)
  • Database: SQLite
