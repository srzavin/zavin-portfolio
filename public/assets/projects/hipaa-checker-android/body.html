Overview

In today's digital age, safeguarding personal health information is paramount. Whether you're a healthcare professional, developer, or an individual concerned about data privacy, ensuring that your applications adhere to the Health Insurance Portability and Accountability Act (HIPAA) standards is crucial.

The HIPAA Checker Android app is a comprehensive solution that allows users to verify the HIPAA compliance of their installed applications. It empowers users to take control of data security with a few simple steps.

Features

  • Complete native Android application developed from scratch using Android Studio.
  • User Interface (UI) fully implemented using XML layouts.
  • Secure user authentication with Signup and Logout API integrations.
  • Fetched and displayed relevant data from the backend on the front end.
  • Implemented a system to list all installed apps on the phone.
  • Allowed users to select and upload APK files for HIPAA compliance scanning.
  • Displayed compliance reports from the backend after scanning.

Technologies Used

  • Languages: Kotlin, XML
  • Platform: Android Studio
  • Backend Communication: REST APIs (Ruby on Rails)
  • Other Tools: Google Play Billing API (for payment handling)
