🔧 Overview

This system was designed to monitor and evaluate productivity in a factory production line environment. By combining Arduino microcontrollers with RFID tags and sensor data, the solution enables real-time tracking of individual worker activity and overall efficiency.

📌 Key Features

  • 📡 RFID-based Worker Identification: Tracks each worker using RFID tags scanned during task execution
  • 🪑 Chair Pressure Sensors: Detects whether workers are present at their workstations
  • 📈 Productivity Metrics: Calculates work time, idle time, and task count per worker
  • 📊 Efficiency Reports: Aggregates data to provide insights on performance across the entire line

🛠 Technology Stack

  • Microcontroller: Arduino UNO
  • Sensors: RFID reader modules and pressure sensors
  • Data Flow: RFID scans + sensor readings → Arduino → serial data log

🎯 Goals & Benefits

  • ⚙️ Automate monitoring of production workers
  • 🕒 Reduce manual supervision time and effort
  • 📉 Identify bottlenecks and idle time accurately
  • 📥 Store and process data for further analysis or dashboard visualization
