Overview

This project presents the design and development of an Autonomous Delivery Robot, a self-driving, computer-vision-based vehicle designed to solve last-mile delivery challenges. It focuses on creating an efficient, cost-effective robot that can autonomously navigate urban environments using machine learning, real-time object detection, and GPS-based navigation.

Objectives

  • Improve last-mile delivery with autonomy
  • Integrate AI-based navigation using computer vision
  • Detect lanes, obstacles, and signs using deep learning
  • Ensure secure delivery via NFC authentication

Key Features

  • Self-driving robot built on Raspberry Pi and Arduino
  • GPS and GraphHopper API for navigation
  • Camera-based CNN for lane and obstacle detection
  • Uses SSD MobileNet V3 for real-time object recognition
  • Secure OTP-based parcel retrieval via NFC

Technical Specifications

  • Chassis: Steel and aluminum frame with two independent motors
  • Motor Driver: BTS7960 H-Bridge
  • Power: 24V lead-acid battery for motors; power bank for Raspberry Pi
  • Sensors: Sonar (HC-SR04), GPS module
  • Controller: PS4 DualShock used for data collection

AI & Model Training

  • Data collected by driving the robot manually
  • Preprocessed via cropping, YUV colorspace conversion, and augmentation
  • Trained using a 9-layer CNN inspired by NVIDIA’s end-to-end learning model
  • Model predicts steering angle from front camera feed

Algorithms & Modules

  • Lane Detection: Color thresholding, perspective warping, and histogram analysis
  • Object Detection: SSD MobileNet V3 with OpenCV and COCO dataset
  • Path Planning: Modified A* algorithm using GraphHopper for dynamic rerouting

Testing & Results

  • Vehicle successfully stops for pedestrians using image + sonar detection
  • Follows lanes and corrects course using real-time inference
  • Coordinates and heading retrieved from GPS for turning and stopping decisions

Limitations

  • Limited by Raspberry Pi processing power
  • Low-quality sensors introduce some noise
  • Does not perform optimally in unpredictable or extreme environments

Future Improvements

  • Upgrade to high-precision sensors and better onboard hardware
  • Train with more diverse and domain-specific datasets
  • Extend functionality with braking and throttle automation
